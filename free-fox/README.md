# Free Fox

A separate browser-based AI interface built around OpenRouter free-model API support, by Monty Kubasek.

- [Launch current root-line build](index.html): `freefox-v01i.html` (v0.1(i)).
- Historical builds: [v0.1(a)](legacy/freefox-v01a.html), [v0.1(c)](legacy/freefox-v01c.html), [v0.1(f)](legacy/freefox-v01f.html), [v0.1(k)](legacy/freefox-v01k.html).
- Shared controls and artwork: `../shared/`.

The previously archived v0.1(k) has not been promoted automatically. Model availability and provider limits are determined upstream; “free-model” does not mean the app requires no API key.

Serve the whole repository from its root (`python3 -m http.server 8000`), then open `/free-fox/`. No build step is required. Source behaviour and browser-storage keys are unchanged; only local asset paths were adjusted for the new directories.
