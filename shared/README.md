# Shared assets

Artwork and interface controls shared by the Fox applications.

- `avatar/`: engine portraits.
- `callsign/`: engine logos and Free Fox callsigns.
- `icons/`: shared SVG controls.
- `images/`: artwork previously at repository root.
- `legacy/`: historical images previously under `legacy/` (including the distinct historical `fox_icon.png`).

Every original asset is retained byte-for-byte. Serve this folder alongside all three project folders.
